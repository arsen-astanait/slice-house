# Slice House

Slice House is a responsive multi-page pizza restaurant website created for the Web Technologies course project.

## Live website

[https://slice-house-asik3.netlify.app/](https://slice-house.netlify.app)

## Pages

- Home (`index.html`)
- Menu (`menu.html`)
- Locations (`locations.html`)
- About Us (`about.html`)
- Careers (`careers.html`)
- Contact (`contact.html`)

## Technologies used

- HTML5 for page structure and semantic content
- CSS3 for custom styling and responsive adjustments
- Flexbox for flexible component layouts
- Bootstrap for the responsive grid, navbar, cards, carousel, offcanvas cart, forms, buttons, table styling, spacing utilities and responsive classes
- JavaScript for the shopping cart, localStorage and contact form interactions

## Responsiveness

The website is designed for desktop, tablet and mobile screens. It uses Bootstrap responsive grid classes such as `col-12`, `col-sm-*`, `col-md-*` and `col-lg-*`, together with custom media queries in `style.css`.
